# 0x08. C - Recursion

This project covers the concept of recursion in C programming.  
Recursion is a method where a function calls itself to solve smaller instances of the same problem.

## Learning Objectives

By the end of this project, you should understand:
- What recursion is
- How to implement recursion
- When to use recursion
- When recursion should not be used
- How to write recursive functions in C
- Restrictions such as:
  - No loops allowed
  - No static variables
  - No use of standard library functions (`printf`, `puts`, `strlen`, etc.)
  - Only `_putchar` is allowed for output

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`
- Compilation:  

- All files must end with a newline
- All prototypes must be in the header file `main.h`
- No more than 5 functions per file
- No global variables

## Files & Descriptions
| File | Prototype | Description |
|------|-----------|-------------|
| `0-puts_recursion.c` | `void _puts_recursion(char *s);` | Prints a string using recursion |
| `1-print_rev_recursion.c` | `void _print_rev_recursion(char *s);` | Prints a string in reverse |
| `2-strlen_recursion.c` | `int _strlen_recursion(char *s);` | Returns length of a string |
| `3-factorial.c` | `int factorial(int n);` | Computes factorial of a number |
| `4-pow_recursion.c` | `int _pow_recursion(int x, int y);` | Returns x^y using recursion |
| `5-sqrt_recursion.c` | `int _sqrt_recursion(int n);` | Natural square root of n |
| `6-is_prime_number.c` | `int is_prime_number(int n);` | Checks for prime number |
| `100-is_palindrome.c` | `int is_palindrome(char *s);` | Checks if a string is a palindrome |
| `101-wildcmp.c` | `int wildcmp(char *s1, char *s2);` | Compares strings with wildcard `*` |
