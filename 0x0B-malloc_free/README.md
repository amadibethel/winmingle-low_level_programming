# WinMingle Community – 0x0B. C: malloc & free

This project covers dynamic memory allocation in C using `malloc` and `free`.  
Students learn how to correctly allocate, manage, and free heap memory while avoiding leaks.

---

## Learning Objectives

By completing this project, you should be able to:

- Understand automatic vs dynamic memory (stack vs heap)
- Use `malloc` and `free` safely
- Prevent memory leaks and dangling pointers
- Allocate and free 1D and 2D dynamic arrays
- Duplicate and concatenate strings using heap memory
- Construct strings from program arguments
- Tokenize (split) a string into words dynamically

## Requirements

- No global variables
- Max 5 functions per file
- Only `malloc`, `free`, and `_putchar` allowed inside tasks
- All prototypes must be in `main.h`
- All files end with a newline
